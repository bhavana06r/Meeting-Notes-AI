\# 📝 Meeting Notes AI



\### Transform Meeting Recordings into Smart, Structured Notes



Meeting Notes AI is an AI-powered web application that converts meeting audio recordings into meaningful and well-organized meeting notes. It uses speech-to-text technology and Generative AI to automatically generate meeting summaries, key discussion points, decisions, deadlines, and action items.



\## 🚀 Features



\- \*\*Audio Upload:\*\* Upload meeting recordings in WAV, MP3, FLAC, OGG and M4A formats.

\- \*\*Audio Transcription:\*\* Convert speech into text using Gnani AI.

\- \*\*AI-Powered Summarization:\*\* Generate concise meeting summaries using Groq AI.

\- \*\*Key Discussion Points:\*\* Extract important topics discussed during meetings.

\- \*\*Action Items:\*\* Identify assigned tasks and responsibilities.

\- \*\*Deadline Tracking:\*\* Organize important project deadlines.

\- \*\*Download Meeting Notes:\*\* Download generated meeting notes for future reference.

\## ⚙️ Installation and Setup



\### 1. Clone the repository



```bash

git clone https://github.com/bhavana06r/Meeting-Notes-AI.git

cd Meeting-Notes-AI

```



\### 2. Install dependencies



```bash

pip install -r requirements.txt

```



\### 3. Configure API Keys



Create a `.streamlit/secrets.toml` file and add your API credentials:



```toml

GROQ\_API\_KEY = "your\_groq\_api\_key"

GNANI\_API\_KEY = "your\_gnani\_api\_key"

```



Never upload your actual API keys to GitHub.



\### 4. Run the application



```bash

streamlit run app.py

```



The application will open in your local browser.



\## 📌 How It Works



1\. Open the Meeting Notes AI application.

2\. Upload a meeting audio recording.

3\. Click the Transcribe Audio button.

4\. Review the generated meeting transcript.

5\. Click Generate Meeting Notes.

6\. View the meeting summary, key discussion points and action items.

7\. Download the generated meeting notes.



\## 🎯 Project Objective



The main objective of Meeting Notes AI is to reduce the time spent manually preparing meeting minutes. It improves productivity by automatically converting conversations into structured, readable and actionable meeting documentation.
